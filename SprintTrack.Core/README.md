# SprintTrack

SprintTrack is a modular .NET solution for sprint planning and tracking.

## Projects
- `SprintTrack.Core`: Core business logic and models.
- `SprintTrack.Playground`: Console app for testing and experimentation.

## Branching Strategy
We use Git Flow:
- `main`: Production-ready code
- `develop`: Active development
- `feature/*`: New features
- `bugfix/*`: Fixes
- `release/*`: Pre-release staging
